Architecture Notes
Networking: Tailscale gives every machine a stable identity across changing IPs; Cloudflare Zero Trust exposes public services without opening a single inbound port. CoreDNS instability forced bypassing cluster DNS — pods run hostNetwork: true with dnsPolicy: Default, and Prometheus ClusterIPs are pinned directly into the Grafana datasource.
Incidents, diagnosed live: The SQLite-backed k3s API server timed out under combined load from Nextcloud jobs, qBittorrent rechecks, and Tailscale IP thrashing causing 1.5s slow inserts on every node heartbeat. A power failure corrupted an external drive's filesystem — recovered with e2fsck -f -b 32768, no data lost. Both fixed without taking the cluster down.
Agent workloads: A persistent headless Chromium (systemd + Xvfb) owns browser state between agent runs; Claude Code attaches over CDP via the Playwright MCP server. Credentials never pass through a model — agents inherit logged-in sessions from the persistent profile.
